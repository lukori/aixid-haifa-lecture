# AIxID - i want to be there

A 15-minute talk by Luka Or (Haifa, 3.11.26), converted from `Luka or_AIxID_e.pptx` to one HTML page.

Open `index.html` in Chrome (works offline), press **F** for full screen.

- Next: → / ↓ / PageDown / Space / Enter / click. Back: ← / ↑ / PageUp.
- Slide 23 loops silently on its own. Slide 25 waits: the first press plays the film with sound, the next moves on.
- Links on slides 23, 26 and 27 open in a new tab and need internet.
- `#N` in the address opens slide N.

`assets/` holds the deck's original images and videos. The film on slide 25 is the copy embedded in the pptx, not a YouTube stream.
